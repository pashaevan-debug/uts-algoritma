# uts-algoritma
Nama : Pasha evan gipari
Nim : C2583207039
KELAS : PTI3A
Program ini dibuat menggunakan bahasa C untuk mengelola stok dan penjualan kantin kampus. Fitur yang tersedia meliputi melihat, menambah, mengubah, mencari, dan mengurutkan produk, melakukan transaksi penjualan, serta menambah stok barang. Program juga dapat menampilkan laporan penjualan dan memberikan peringatan jika stok produk mulai menipis. Dengan adanya program ini, pengelolaan data produk dan penjualan kantin menjadi lebih mudah, cepat, dan teratur.
